# Foody — личный дневник КБЖУ для iPhone

Приложение для одного пользователя: все данные хранятся на телефоне, продукты вводятся вручную или
**распознаются с фото этикетки** LLM-моделью (Claude или GPT), есть сохранённые приёмы пищи, рецепты с расчётом по
весу готового блюда, дневные цели и статистика перебора/недобора за день, неделю и месяц. Оптимизировано под
iPhone 11, iOS 17+, SwiftUI + SwiftData, минималистичный дизайн, тёмная тема.

## Возможности

- **Дневник** по приёмам пищи (завтрак, обед, ужин, перекусы): кольцо калорий и полоски Б/Ж/У относительно цели,
  остаток калорий, клетчатка/сахара/насыщенные/соль против лимитов, навигация по дням.
- **Продукты** со всеми полями декларации ЕС (энергия в кДж/ккал, жиры и их виды, углеводы/сахара/полиолы/крахмал,
  клетчатка, белки, соль/натрий, холестерин, алкоголь, витамины и минералы с % NRV), порция, избранное, поиск.
- **Фото этикетки → карточка продукта**: модель возвращает строгий JSON, приложение показывает уверенность и заметки,
  пользователь проверяет и сохраняет. Поддержка Anthropic (Claude) и OpenAI (Responses API), ключи в Keychain.
- **Сохранённые приёмы пищи** — «мой обычный завтрак» добавляется одним касанием.
- **Рецепты** — КБЖУ на 100 г готового блюда по взвешенному весу и на стандартную порцию.
- **Цели** с историей и калькулятором (Миффлин — Сан Жеор).
- **Статистика** день/неделя/месяц: калории по дням с линией цели, перебор/недобор по каждому показателю,
  средние за учтённые дни, разбивка по приёмам пищи.
- **Резервная копия** одним JSON-файлом, без облака.

## Быстрый старт

```bash
git clone https://github.com/uncoll/foodyios.git
cd foodyios
open Foody.xcodeproj            # выбрать Team в Signing & Capabilities, Run на iPhone
swift test --package-path FoodyCore   # тесты ядра (работают и на Linux)
```

## Статус

Код написан в облачной сессии без доступа к macOS: ядро (`FoodyCore`) покрыто тестами, iOS-часть проверяется
workflow `iOS build` на GitHub Actions (macOS-раннер, Xcode 16.4) — он же собирает неподписанный IPA.
Если при первом открытии в Xcode появятся ошибки компиляции, пришлите их текст — правки будут точечными.
