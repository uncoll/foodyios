# Foody — дневник КБЖУ для iPhone

Личное iOS-приложение (один пользователь, все данные на телефоне) для учёта калорий, белков, жиров и углеводов
с распознаванием этикеток по фото через LLM. Оптимизировано под iPhone 11, iOS 17+.

Репозиторий пока наполняется — см. `docs/` и `tools/label-bench/` (бенчмарк моделей распознавания этикеток).
