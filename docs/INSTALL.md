# Установка Foody на iPhone 11

Приложение не публикуется в App Store — оно личное. Есть два пути: через Xcode (основной) и через готовый
неподписанный IPA из GitHub Actions + Sideloadly/AltStore (если не хочется открывать Xcode).

## Что понадобится

- Mac с **Xcode 16.x или 26.x** (проект в формате Xcode 16; iPhone 11 на iOS 18 требует Xcode 16, на iOS 26 — Xcode 26).
  Xcode бесплатен в Mac App Store (~15 ГБ).
- Кабель или Wi-Fi-подключение iPhone к Mac.
- Apple ID. **Бесплатный** аккаунт позволяет ставить приложение на свой телефон, но подпись живёт 7 дней
  (потом нужно снова нажать Run в Xcode). С **платным Apple Developer Program** ($99/год) подпись действует год.

## Путь 1. Xcode (рекомендуется)

1. Склонируйте репозиторий и откройте проект:
   ```bash
   git clone https://github.com/uncoll/foodyios.git
   cd foodyios
   open Foody.xcodeproj
   ```
   Если проект не открывается (старый Xcode), сгенерируйте его заново:
   `brew install xcodegen && xcodegen generate` — появится такой же `Foody.xcodeproj` из `project.yml`.
2. Xcode подтянет локальный пакет `FoodyCore` автоматически (он лежит в репозитории, интернет не нужен).
3. Выберите таргет **Foody** → вкладка **Signing & Capabilities**:
   - поставьте галочку *Automatically manage signing*;
   - в **Team** выберите свой Apple ID (если его нет — Xcode → Settings → Accounts → «+» → войдите);
   - при необходимости измените **Bundle Identifier** на уникальный, например `com.<вашник>.foody`
     (бесплатный аккаунт допускает до 10 разных идентификаторов в неделю).
4. Подключите iPhone, разблокируйте его, при первом подключении нажмите «Доверять» на телефоне.
   На iPhone включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**
   (появляется после первого подключения к Xcode), телефон перезагрузится.
5. В Xcode вверху выберите свой iPhone как устройство запуска и нажмите **Run (⌘R)**. Первая сборка занимает 1–3 минуты.
6. При первом запуске iOS скажет «Ненадёжный разработчик». Откройте на iPhone
   **Настройки → Основные → VPN и управление устройством → <ваш Apple ID> → Доверять**. Запустите Foody ещё раз.

С бесплатным аккаунтом через 7 дней приложение перестанет открываться — просто подключите телефон и снова
нажмите Run (данные не пропадут: база остаётся на устройстве). С платным аккаунтом — раз в год.

Чтобы обновлять приложение без Mac под рукой, можно раз в год делать Archive → Distribute → Ad Hoc/Development и
устанавливать IPA через Apple Configurator, но для одного телефона проще Run из Xcode.

## Путь 2. Неподписанный IPA из GitHub Actions + Sideloadly

При каждом пуше workflow **iOS build** собирает `Foody-unsigned.ipa` (артефакт `Foody-unsigned-ipa` в разделе Actions).

1. Скачайте артефакт, распакуйте — получится `Foody-unsigned.ipa`.
2. Установите [Sideloadly](https://sideloadly.io) (macOS/Windows) или AltStore.
3. Подключите iPhone, перетащите IPA в Sideloadly, введите Apple ID — программа подпишет приложение вашим
   аккаунтом и установит. Ограничения те же: бесплатный аккаунт — 7 дней, потом переустановка (данные сохраняются).
4. После установки подтвердите доверие разработчику (см. п. 6 выше).

## Первая настройка приложения

1. **Настройки → Дневные цели** — введите свою норму или нажмите «Рассчитать по параметрам тела».
2. **Настройки → Распознавание этикеток** — выберите поставщика (по умолчанию Anthropic / Claude Sonnet 5),
   вставьте API-ключ. Ключ создаётся в консоли поставщика:
   - Anthropic: https://console.anthropic.com/settings/keys
   - OpenAI: https://platform.openai.com/api-keys
   Ключ хранится в Keychain телефона и никуда, кроме API поставщика, не отправляется.
3. Добавьте продукты: вкладка **Продукты → +** → «Сфотографировать этикетку» или «Ввести вручную».
4. Ведите дневник: вкладка **Дневник**, кнопка «+» у нужного приёма пищи.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| «Failed to register bundle identifier» | Смените Bundle Identifier на уникальный (Signing & Capabilities) |
| «Unable to install… device not in developer mode» | Включите Режим разработчика на iPhone (см. шаг 4) |
| «Could not launch — untrusted developer» | Настройки → Основные → VPN и управление устройством → Доверять |
| Через неделю приложение не открывается | Бесплатная подпись истекла — снова Run из Xcode (или переустановка через Sideloadly) |
| Сканирование пишет «Ключ отклонён (401)» | Проверьте ключ и выбранного поставщика в Настройках; для OpenAI нужен платёжный метод в аккаунте |
| Сканирование пишет «Модель не найдена (404)» | Ваш аккаунт не имеет доступа к этой модели — выберите другую в списке или укажите id вручную |
| Ошибка сборки в Xcode | Скопируйте текст ошибки и пришлите его в чат — код собирался «вслепую» (в облаке без macOS), мелкие правки возможны |

## Резервные копии

Настройки → **Экспортировать резервную копию** сохраняет все данные в один JSON-файл (в «Файлы», iCloud Drive или
по AirDrop). Восстановление — «Восстановить из копии». Так можно перенести данные на новый телефон, не
пользуясь облаком приложения.
